# Training Plan — Arm-Focused Superset Split

## Timer setup
One **2:30 repeat timer**, started on your first work set.
Each ping = **start the next A exercise**. Do the B exercise anywhere in the gap.
The A-A start times are the only anchors that matter; B is flexible.

- All exercises **3×10**, except **abs 3×20**.
- Rest logic: A (the heavier/limiting move) is protected by the 2:30 cadence; B slots into the gap.

---

## Warm-up
- **Rower** — 60 kcal

---

## Finisher
- **Mixed plank** — 140s (2:20). The 2:30 timer covers this too; the ping lands ~10s after you finish.

---

## Notes
- **Incline press bar weight** is still TBD — check whether it's a full Olympic bar (20 kg), a lighter fixed bar, or a counterbalanced Smith machine, then add it to the 17 kg/side.
- **Fatigue on sets 2–3:** if *one* exercise drops reps, skip a ping there (let that set run to the next beep = 5:00 rest). If *most* exercises fade, raise the whole timer to 2:45. If a move needs extra time every week, it's a loading issue — shave a little weight instead.
- **Rest philosophy:** 2:30 is ample for hypertrophy; longer rest doesn't hurt growth. The timer is for consistency and pace, not for cutting recovery you needed.
