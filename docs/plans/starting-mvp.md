# Fitness Tracker MVP: Basic user requirements summary

I need a tool to guide my workout and track progress and consistency. 
My example workout plan is @training-plan.md

Alongside with this plan in need at the very least
 - a timer which tells me when to start the next set (a 30 min workout 45min pause fitness timer for now)
 - a way to update the current weights
 - a way to keep track of progress on weights, and possibly display it in a graph
 - a way to keep track of how often i hit the gym, when i skip

 The tool can be an android app fully web based, as long as i can access to my personal data with some basic confidentiality.
